Notes:
- Backend modules follow one pattern: `routes.ts`, `controller.ts`, `service.ts` and `schema.ts` (Zod).
- Middleware holds authentication, forced password change, role check, scope check (school, faculty, department, level), session lock, rate limiting, validation, cron authentication, audit and error handling.
- The cat SVG components (crying, happy, calm) live in `frontend/src/components/cats/`. The logo, favicon and social preview image are in `frontend/public/`.
- Self-hosted fonts (Arimo and Tinos) are in `frontend/public/fonts/` and declared in `frontend/src/styles/fonts.css`.
- Agent instruction files at the root: `AGENTS.md` is the main file. `CLAUDE.md`, `GEMINI.md` and `CODEX.md` point to it.
